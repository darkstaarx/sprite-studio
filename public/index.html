✓Akaun bersambung

Nak tambah akaun lain? Ikut langkah di bawah — tapi buka pautan kebenaran tu dalam tetingkap Incognito, kalau tidak Meta akan guna akaun yang sedang log masuk sekarang.

AApp Threads di Meta
  1. Buka developers.facebook.com/apps → Create app → use case Access the Threads API
  2. Tambah kebenaran threads_basic dan threads_content_publish
  3. App roles → Add People → Threads Tester, taip username kau tanpa @
  4. Dalam app Threads: ☰ → Settings → More settings → Website permissions → tab Invites → Accept. Akaun kena public
  5. Use case Threads → Settings: isi ketiga-tiga medan (Redirect Callback URLs, Uninstall, Delete) dengan alamat di bawah, klik cadangan yang muncul, Save, lepas tu F5 untuk sahkan ia tersimpan

BApprove
Lepas approve, browser akan papar “site can’t be reached”. Itu betul — domain tu sengaja tak wujud. Yang kita perlukan cuma URL dalam bar alamat.

Untuk akaun kedua: cara paling selamat ialah profil browser berasingan (Edge: Settings → Profiles → Add profile; Chrome: Add another profile), atau log keluar akaun pertama dalam tetingkap biasa dan log masuk akaun kedua.

Elak InPrivate/Incognito kalau boleh — perlindungan penjejakan yang ketat menyekat cookie pihak ketiga, dan OAuth Meta selalunya gagal dengan ralat umum kod 1 di situ.

Klik bar alamat → Ctrl+A → Ctrl+C. Bentuknya https://…/callback?code=AQB…. Kod luput dalam beberapa minit dan sekali guna — kalau gagal, ulang langkah B.

1Link produk
Link affiliate kau dikekalkan bulat-bulat dan dipakai dalam balasan pertama. Sistem buka link pendek dan kesan nama, harga dan gambar sendiri.

2Gaya tulisan
Setiap gaya ada struktur sendiri. Cerita sebenar paling kuat, tapi ia perlukan butiran betul — bila, kat mana, siapa cakap apa. Kalau tiada, AI diarah jangan reka; dia akan tulis pemerhatian.
3Bila keluar
Sekarang bermakna post tak dijadual — kau tekan "Terbit sekarang" bila dah puas hati. Waktu orang Malaysia scroll: 9–11 malam paling kuat, 12:30–2 petang kedua, pagi sebelum kerja ketiga. Post berjadual hanya keluar kalau komputer ni hidup.

Biar mati — orang kena klik link untuk tahu harga.

AIEnjin ayat
Model mesti ditulis tepat seperti id dalam senarai pembekal kau (selalunya huruf kecil berselang sengkang), bukan nama paparan. Base URL ambil dari halaman Docs pembekal — biasanya berakhir dengan /v1. Tanpa AI, yang keluar cuma rangka ayat. Ada tiga jalan: pasang key (Nous Portal / OpenRouter), guna Ollama tempatan, atau tanpa key langsung — copy arahan, jalankan dalam Hermes Agent atau ChatGPT, tampal jawapan balik.

✓Hasil

📅Rancang seminggu
Satu akaun, satu niche. App campur post jualan dengan kandungan nilai ikut nisbah yang kau set, dan sebarkan merentas hari supaya jualan tak berlonggok. Nisbah 1:2 bermakna satu post jualan untuk dua post tips.

→Bila post keluar nanti
Threads kira balasan, bukan like. Lima belas minit selepas post ialah tetingkap paling penting — kalau kau hilang, post tu mati walaupun ayatnya bagus.
  • 15 minit sebelum: like dan balas dalam niche kau
  • Lepas post, duduk 15 minit — balas semua yang masuk
  • Balas setiap komen, walaupun lambat
  • Komen berisi di post orang lain — bukan “nice post”
  • Letak link dalam balasan pertama, bukan dalam post

↔Tanpa API key
Copy arahan penuh, jalankan dalam AI kau sendiri (Hermes Agent, ChatGPT, Claude), lepas tu tampal jawapan dia balik. Hasilnya sama macam kalau key dipasang.
