Eksport ke Metricool

Template Metricool berubah dari masa ke masa. Tampal baris header sebenar dari fail template kau di sini — eksport akan padan ikut nama kolum tu. Kalau kau biar default, aku guna susunan lazim: Text, Date, Time, rangkaian TRUE/FALSE, Type of Post, Brand Name, Picture Url 1–10.

CSV → import terus dalam Metricool Calendar (tiada API perlu, jalan pada semua plan). JSON → untuk scripts/metricool_push.py kalau plan kau ada akses API.

Penyedia LLM (mod auto)

Key disimpan dalam localStorage browser ni sahaja — tak dihantar ke mana-mana kecuali base URL yang kau isi. Sebab tu tool ni untuk kegunaan sendiri, jangan host secara public dengan key di dalam.
